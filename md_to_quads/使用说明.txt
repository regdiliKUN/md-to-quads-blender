================================================================
MD布料转四边面（傻瓜式一键版）使用说明  v1.1.0
—— 在 Blender 里把 Marvelous Designer 的三角面布料，直接变成带正确 UV 的完美四边面
================================================================

本插件把 Maya 上的「MD布料转四边面」流程搬到了 Blender，并做到：
  · 不用 Maya
  · 不用任何付费/破解的重拓扑器（重拓扑用 Blender 内置的 Quadriflow）
  · 支持 Blender 2.80 / 2.9x / 3.x / 4.x（含 4.2+），Windows / Mac / Linux 全平台

压缩包里就两个文件：
  __init__.py      = 插件本体（纯 Blender Python，安全无毒）
  使用说明.txt     = 本文件

----------------------------------------------------------------
一、安装（第一次做，之后不用再装）
----------------------------------------------------------------
1. 解压本压缩包，记住 __init__.py 所在位置。
2. 打开 Blender。
3. 编辑 → 偏好设置 → 插件（Add-ons）。
4. 右上角「从磁盘安装 / Install from Disk」（4.1 及更早叫「从文件安装 / Install from File」）。
5. 选中本包里的 __init__.py，确认。
6. 在插件列表里找到「MD布料转四边面」，把前面的勾打上。
   （4.2+ 会以「传统插件」方式安装，完全正常，放心勾选。）
7. 关掉偏好设置窗口。3D 视图按 N 打开右侧栏，最右边竖排标签里就有「MD转四边面」。

----------------------------------------------------------------
二、在 Marvelous Designer 里导出（关键一步）
----------------------------------------------------------------
1. 导出「平铺状态的板片」为 OBJ（这是三角面平板，后面当 01）。
2. 导出「3D 穿着状态的衣服」为 OBJ（这是三角面衣服，后面当 03）。
3. 两次导出都务必勾选「统一UV坐标 / Unified UV Coordinates」选项。
   —— 这一步最重要：01 和 03 必须用同一套 UV，插件才能把形状套回去。

----------------------------------------------------------------
三、在 Blender 里一键转换（日常就这 3 步）
----------------------------------------------------------------
1. 面板「① 导入」→ 点「导入 MD 的 OBJ」，在弹窗里同时选中上面的两个 OBJ，确认导入。
   （导入后这两个模型会被自动选中。）
2. 面板「② 一键转换」→ 点「🪄 一键 MD→四边面（全自动）」。
   插件会自动：识别哪块是平板(01)、哪块是衣服(03)
               → 用 Quadriflow 把平板重拓扑成四边面(02)
               → 把 01 的 UV 传给 02
               → 按 UV 把 02 套到 03 的衣服形状上
3. 完成！场景里多出一个带正确 UV 的完美四边面衣服（默认已自动删掉两个源模型）。

就这么简单。不需要手动拖任何东西，也不需要去 Maya。

----------------------------------------------------------------
四、想自己调的时候（高级/手动，一般不用碰）
----------------------------------------------------------------
· 四边面密度：面板里「四边面目标面数」越大越密（默认 4000）。
· 保留硬边 / 保留边界：勾上能让重拓扑更贴合原板片轮廓。
· 手动分步：可单独点「只传递 UV」/「只传递 顶点位置」排查问题。
· 手动指定 01/02/03：在「高级/手动」里用吸管分别指定三个物体，再点「传递 UV + 顶点位置」。

----------------------------------------------------------------
五、常见报错与处理
----------------------------------------------------------------
· “01 没有UV / 03 没有UV”  → 回 MD 重新导出，确认勾了「统一UV坐标」。
· “请先导入 MD 的两个 OBJ” → 先点「导入 MD 的 OBJ」导入两个文件。
· “Quadriflow 重拓扑失败”  → 板片不是干净的片状体（有破面/非流形）；
                              先用 Blender 修一下拓扑，或降低目标面数再试。
· 大网格（几十万面）传递要等几秒到几十秒，属正常，Blender 可能短暂无响应。

----------------------------------------------------------------
六、版本与兼容性
----------------------------------------------------------------
· Blender：2.80 起全部支持（含 4.2+，以传统插件安装）。numpy 自 2.79 起随附，无需另装。
· 重拓扑器：用 Blender 内置 Quadriflow（2.79+ 自带），不依赖任何外部程序。
· 原始 Maya 脚本对应 transferAttributes（Maya 2016+），本插件即其 Blender 替代，无需 Maya。
· 许可证：GPL-3.0-or-later（与原 Maya 脚本同源衍生）。

祝使用愉快。
