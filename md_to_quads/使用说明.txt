================================================================
MD布料转四边面  使用说明  v1.3.0
—— 在 Blender 里把 Marvelous Designer 的三角面布料，直接变成带正确 UV 的四边面
================================================================

本插件把 Maya 上的「MD布料转四边面」流程搬到了 Blender，并做到：
  · 不用 Maya
  · 不用任何付费/破解的重拓扑器
  · 支持 Blender 2.80 / 2.9x / 3.x / 4.x（含 4.2+），Windows / Mac / Linux 全平台

三个角色（面板里都用 ①②③ 标好了，不用记编号以外的东西）：
  ① 平板 = MD「平铺状态」导出的三角面布料   → 提供 UV，也是生成四边面的输入
  ② 四边面 = 由①生成的四边面网格           → 最终结果
  ③ 衣服 = MD「穿着/3D 状态」导出的三角面   → 提供最终形状

----------------------------------------------------------------
一、安装（第一次做，之后不用再装）
----------------------------------------------------------------
【方式 A · 一键启动，推荐】
用的是「md_to_quads-1.3.0-完整包.zip」，解压后双击就行：

  · 双击「一键启动.bat」
      → 自动找 Blender → 装/更新插件 → 启用 → 打开 Blender，全程不用做选择。
  · 双击「一键助手.bat」
      → 菜单版，可选：① 安装并启动 ② 创建桌面快捷方式 ③ 两者一起
        ④ 只启动 Blender ⑤ 只装插件 ⑥ 忘记记住的 Blender 路径。
  · 双击「创建桌面快捷方式.bat」
      → 桌面会出现两个图标：
        「MD布料转四边面 · 一键助手」= 以后双击就装好并打开 Blender
        「MD布料转四边面 · 文件目录」 = 一键打开本文件夹
  · Mac / Linux：终端执行 ./一键助手.sh（或双击它）。

  说明：脚本需要 Python 3；系统里没有的话会自动改用 Blender 自带的 Python。
  Blender 装在非常规位置时，会让你指一次路径，之后就记住了（存在 .blender_path 里）。

【方式 B · 手动安装】
1. 解压 md_to_quads-1.3.0.zip。
2. 打开 Blender → 编辑 → 偏好设置 → 插件（Add-ons）。
3. 右上角「从磁盘安装 / Install from Disk」（4.1 及更早叫「从文件安装」）。
4. 选中压缩包里的 md_to_quads-1.3.0.zip（或解压后的 __init__.py），确认。
5. 在插件列表里找到「MD布料转四边面」，把前面的勾打上。
6. 3D 视图按 N 打开右侧栏，最右边的竖排标签里就有「MD转四边面」。

----------------------------------------------------------------
二、在 Marvelous Designer 里导出（关键一步）
----------------------------------------------------------------
1. 导出「平铺状态的板片」为 OBJ（= ① 三角面平板）。
2. 导出「3D 穿着状态的衣服」为 OBJ（= ③ 三角面衣服）。
3. 两次导出都务必勾选「统一UV坐标 / Unified UV Coordinates」。
   —— 这是最容易出错的一步：①和③必须用同一套 UV，插件才能把形状套回去。

----------------------------------------------------------------
三、在 Blender 里转换（日常就这三步）
----------------------------------------------------------------
【① 准备】
· 点「导入 MD 的 OBJ」，在弹窗里同时选中上面两个 OBJ，确认导入。
  导入完成后插件会自动把这两个模型填进 ① 和 ③（面板状态条会提示识别结果）。
· 如果模型已经在场景里：选中这两个网格 → 点「从选择识别」。
  插件按「最扁的是平板、最立体的是衣服」判断，选 3 个时按选择顺序填入 ①②③。

【② 生成四边面】（可跳过，一键转换会自动做）
· 生成方式：
    · 三角面配对（默认，推荐）：直接把三角面两两合并成四边面，
      保留原来的拓扑和 UV，速度最快，全版本可用。
      若结果里三角面较多，把「配对角度阈值」调大（默认 45°）。
    · Quadriflow 重拓扑：按「目标四边面数」重新分布网格，可自由控制密度，
      但会改变拓扑；Blender 4.2 起官方不再自带这个功能，面板会提示。
· 点「生成 ② 四边面」会复制一份①来做，原物体不会被改动。

【③ 完成转换】
· 点「一键生成四边面衣服」：自动完成 生成四边面 → 传 UV → 套回衣服形状。
· 默认会删掉 ①③ 两个源模型（可取消勾选；删错了 Ctrl+Z 就能撤销）。
· 完成后状态条会显示：结果物体名、面数、四边面占比、UV 与顶点命中数、耗时。

----------------------------------------------------------------
四、高级选项（一般不用打开）
----------------------------------------------------------------
· 手动指定 ②：想复用已有的四边面网格时用。
· 已有 UV 时跳过 UV 传递：配对方式下②本来就带着原 UV，跳过更快也更精确。
· 只传 UV / 只套回衣服形状：分步排查问题时用。
  （注意：套形状必须先有 UV，否则会提示先传 UV。）
· 清空：只清面板里的引用，不会删除场景里的任何物体。

----------------------------------------------------------------
五、常见报错与处理
----------------------------------------------------------------
· “①平板没有 UV / ③衣服没有 UV”
    → 回 MD 重新导出，确认勾了「统一UV坐标」。
      面板 ① 区会直接标出「⚠ 无 UV」，不用等到点按钮才发现。
· “还缺：①平板 / ③衣服”
    → 先导入两个 OBJ，或选中两个网格点「从选择识别」。
· “生成四边面失败 / Quadriflow 相关”
    → 当前 Blender 可能没有 Quadriflow（4.2+），改用「三角面配对」即可。
· “四边面占比偏低”
    → 调大「配对角度阈值」；或改用 Quadriflow 重拓扑。
· 形状套歪了
    → 十有八九是 ①③ 的 UV 不是同一套（UV 层名不同时状态条也会提示）。
· 大网格（几十万面）
    → 顶部有进度条，处理可能要几十秒到几分钟，属正常。

----------------------------------------------------------------
六、兼容性与验证
----------------------------------------------------------------
· Blender：2.80 起全部支持（含 4.2+）。numpy 自 2.79 起随附，无需另装。
· 版本差异已在插件内处理：OBJ 导入器（新版 wm.obj_import / 旧版 import_scene.obj）、
  Quadriflow 参数（各版本参数名不同）、三角面合并（不再依赖 4.x 已失效的算子）。
· 已在 Blender 3.6.20 与 4.2.9 LTS 上通过 20 项自动化测试。
· 许可证：GPL-3.0-or-later（与原 Maya 脚本同源衍生）。
